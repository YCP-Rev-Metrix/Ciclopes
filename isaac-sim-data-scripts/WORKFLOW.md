# Synthetic Data Generation Workflow

Complete pipeline for generating YOLO segmentation training data from Isaac Sim 5.1

---

## 📋 Overview

This workflow generates synthetic training data of a ball rolling on a bowling lane using NVIDIA Isaac Sim 5.1, then converts it to YOLO segmentation format.

**Pipeline Steps:**
1. **Generate raw data** in Isaac Sim → RGB + instance/semantic masks
2. **Verify segmentations** using visualization tool
3. **Convert to YOLO format** with train/val split
4. **Train YOLO model** (YOLOv8-seg or similar)

---

## 🎬 Step 1: Generate Data in Isaac Sim

### Scene Setup

Your Isaac Sim scene should have:

- **Lane prim** at `/World/Lane`
  - 18 units long × 1 unit wide
  - Oriented in -X direction (runs from X=+9 to X=-9)
  - Height: Z=0.0008 (0.001m thick)
  
- **Ball prim** at `/World/Sphere`
  - Scale: 0.3 in all directions (diameter = 0.3, radius = 0.15)
  - Will be positioned dynamically by script

- **Camera prim** at `/World/Camera`
  - Already positioned and configured in your scene
  - Script will use this existing camera (no repositioning)

### Run the Script

1. Open Isaac Sim 5.1
2. Load your scene with Lane, Sphere, and Camera prims
3. Open Script Editor (Window → Script Editor)
4. Load and run `run_ball_script_data_gen.py`

**Script Configuration** (edit at top of file):
```python
TOTAL_FRAMES = 5500    # Total frames to generate
EPISODE_LEN  = 30      # Frames per episode (ball resets every 30)
OUT_DIR = "isaac_raw_output"  # Output directory
```

**What it does:**
- Generates 5500 frames (~183 episodes)
- Each episode: ball starts at random (X,Y) position, rolls in -X direction
  - **X randomization**: Starts near +X end (around X=+8 to +8.5)
  - **Y randomization**: Random position across lane width (Y ∈ [-0.3, +0.3])
  - Ball stays fully on lane (accounts for ball radius + margin)
- Outputs to `isaac_raw_output/`:
  - `rgb_XXXX.png` - RGB images
  - `instance_segmentation_XXXX.png` - Instance masks
  - `semantic_segmentation_XXXX.png` - Semantic masks
  - `*_mapping_XXXX.json` - ID mappings

**Expected runtime:** ~30-60 minutes depending on GPU

## 🔍 Step 2: Verify Segmentations

Before converting thousands of frames, visually verify the masks are correct:

```bash
python visualize_segmentation.py --data_dir isaac_raw_output --frame 0 --save
python visualize_segmentation.py --data_dir isaac_raw_output --frame 100 --save
python visualize_segmentation.py --data_dir isaac_raw_output --frame 1000 --save
```

This creates `segmentation_check_frame_XXXX.jpg` showing:
- **Top-left:** Original RGB
- **Top-right:** Instance segmentation (different colors per object)
- **Bottom-left:** Semantic segmentation (lane vs ball classification)
- **Bottom-right:** Legend

### ✅ What to Check:
- Ball is correctly segmented (separate from lane)
- Lane is correctly segmented
- No missing or merged objects
- Masks align with RGB image

## 🔄 Step 3: Convert to YOLO Format

Convert Isaac Sim output to YOLO segmentation format with train/val split:

```bash
python repo_to_yolo_seg.py --in_dir isaac_raw_output --out_dir yolo_dataset --train_val_split 0.9
```

**Parameters:**
- `--in_dir`: Folder with Isaac Sim raw outputs (must contain `rgb_*.png`, `instance_segmentation_*.png`, `semantic_segmentation_*.png`)
- `--out_dir`: Output folder for YOLO dataset (will be created if doesn't exist)
- `--train_val_split`: Fraction for training (default: 1.0 = no split)
  - `0.9` = 90% train, 10% val
  - `0.8` = 80% train, 20% val
  - `1.0` = all data in flat `images/` directory (no split)
- `--workers`: Number of parallel workers (default: CPU count - 1)
  - Use `--workers 1` for single-threaded (slower, good for debugging)
  - Use `--workers 8` to force 8 workers
  - Auto-detection uses all cores minus one

**Performance:**
- Speed: ~4.8 frames/second with multiprocessing (15 workers on test system)
- 5,100 frames expected to complete in ~18 minutes
- Progress bar shows real-time status and ETA

### ✅ Output Structure

When using `--train_val_split 0.9` on 5,500 frames:

```
yolo_dataset/
├── data.yaml                    # YOLO config file
├── images/
│   ├── train/                   # 4,950 training images (90%)
│   └── val/                     # 550 validation images (10%)
└── labels/
    ├── train/                   # 4,950 training labels (polygon format)
    └── val/                     # 550 validation labels
```

### 📄 data.yaml Contents

```yaml
path: /full/path/to/yolo_dataset
train: images/train
val: images/val
names:
  0: lane
  1: ball
```

This file is automatically generated and ready for YOLO training.

### 🎛️ Advanced Options

**Convert with 8 workers:**
```bash
python repo_to_yolo_seg.py --in_dir isaac_raw_output --out_dir yolo_dataset --train_val_split 0.9 --workers 8
```

**Convert all data without train/val split:**
```bash
python repo_to_yolo_seg.py --in_dir isaac_raw_output --out_dir yolo_dataset --train_val_split 1.0
```

**Single-threaded conversion (debugging):**
```bash
python repo_to_yolo_seg.py --in_dir isaac_raw_output --out_dir yolo_dataset --train_val_split 0.9 --workers 1
```

## 🛠️ Utilities

### visualize_segmentation.py

Visualize raw segmentation output from Isaac Sim before conversion. Useful for verifying masks are correct.

**Basic usage:**
```bash
# Display frame 0 interactively (on screen)
python visualize_segmentation.py --data_dir isaac_raw_output --frame 0

# Display frame 100
python visualize_segmentation.py --data_dir isaac_raw_output --frame 100

# Save to file instead of displaying
python visualize_segmentation.py --data_dir isaac_raw_output --frame 50 --save
```

**Output:**
Creates `segmentation_check_frame_XXXX.jpg` with 4 panels:
- **Top-left:** Original RGB image
- **Top-right:** Instance segmentation (different colors per object)
- **Bottom-left:** Semantic segmentation (lane vs ball classification)
- **Bottom-right:** Legend with class names

**Typical workflow:**
```bash
# Check frame 0
python visualize_segmentation.py --data_dir isaac_raw_output --frame 0 --save

# Check middle of dataset
python visualize_segmentation.py --data_dir isaac_raw_output --frame 2700 --save

# Check near end
python visualize_segmentation.py --data_dir isaac_raw_output --frame 5400 --save
```

### visualize_yolo_polygons.py

Visualize YOLO format polygon annotations **after conversion** to verify polygons match objects.

**Basic usage:**
```bash
# Visualize 5 train samples
python visualize_yolo_polygons.py --dataset_dir yolo_dataset --split train --num_samples 5

# Visualize 3 val samples
python visualize_yolo_polygons.py --dataset_dir yolo_dataset --split val --num_samples 3
```

**Parameters:**
- `--dataset_dir`: Path to YOLO dataset (must have `images/train`, `labels/train`, etc.)
- `--split`: Which split to visualize (`train` or `val`)
- `--num_samples`: How many samples to visualize (default: 3)
- `--output_dir`: Where to save visualizations (default: `yolo_viz_checks/`)

**Output:**
Creates visualizations in `yolo_viz_checks/` showing:
- **Green outline:** Lane polygon (class 0)
- **Blue outline:** Ball polygon (class 1)
- **Colored fill:** Semi-transparent filled polygon (30% alpha)
- **Labels:** Class names at polygon centroids

**Typical workflow:**
```bash
# After conversion, verify a few train samples
python visualize_yolo_polygons.py --dataset_dir yolo_dataset --split train --num_samples 5

# Check val samples too
python visualize_yolo_polygons.py --dataset_dir yolo_dataset --split val --num_samples 3

# Check more samples if needed
python visualize_yolo_polygons.py --dataset_dir yolo_dataset --split train --num_samples 20 --output_dir my_checks/
```

**What to verify:**
- ✅ Lane polygon is a 4-point rectangle outlining the lane
- ✅ Ball polygon is a 15-20 point polygon outlining the ball
- ✅ Both polygons are tightly fit to the objects
- ✅ No overlap or merging between lane and ball
- ✅ Polygons follow object boundaries accurately

## 🐛 Troubleshooting

### Isaac Sim Generation Issues

**Problem:** Semantics not appearing in output
- **Fix:** Ensure semantics are set in script:
  ```python
  rep.modify.semantics(prim_paths=[BALL_PRIM], semantic_types=["class"], semantic_values=["ball"])
  rep.modify.semantics(prim_paths=[LANE_PRIM], semantic_types=["class"], semantic_values=["lane"])
  ```

**Problem:** Ball clipping through lane or falling off screen
- **Fix:** Adjust `BALL_Z` in config to account for lane thickness and ball radius
  - Ensure: `BALL_Z = LANE_Z + LANE_THICKNESS + BALL_RADIUS`
  - Example: `0.0008 + 0.001 + 0.15`

**Problem:** All frames look identical (no variation)
- **Fix:** Check that randomization is enabled in `run_ball_script_data_gen.py`:
  ```python
  # Ball position should vary per episode:
  ball_x = np.random.uniform(8.0, 8.5)
  ball_y = np.random.uniform(-0.3, 0.3)
  ```

### Visualization Issues

**Problem:** visualize_segmentation.py not finding frame
- **Fix:** Check frame exists:
  ```bash
  ls isaac_raw_output/rgb_0000.png  # Should exist
  ```
- Frame numbering is 0-indexed, not 1-indexed

**Problem:** visualize_yolo_polygons.py showing wrong directory structure
- **Fix:** Ensure conversion completed with train/val split:
  ```bash
  ls yolo_dataset/images/train/        # Should have .jpg files
  ls yolo_dataset/labels/train/        # Should have .txt files
  ```

### Conversion Issues

**Problem:** "No (rgb, instance, semantic) bundles found"
- **Fix:** Check input directory naming:
  - Files must match patterns: `rgb_*.png`, `instance_segmentation_*.png`, `semantic_segmentation_*.png`
  - Check that JSON mapping files exist alongside images

**Problem:** Conversion is very slow
- **Fix:** Increase worker count:
  ```bash
  python repo_to_yolo_seg.py ... --workers 16  # Use more cores
  ```
- Or reduce if getting memory errors:
  ```bash
  python repo_to_yolo_seg.py ... --workers 4   # Use fewer cores
  ```

**Problem:** Out of memory during conversion
- **Fix:** Reduce worker count:
  ```bash
  python repo_to_yolo_seg.py ... --workers 2
  ```
- Or convert in smaller batches

**Problem:** Empty label files or missing labels
- **Fix:** Verify the mappings match your Isaac Sim configuration:
  1. Check one raw instance mask with `visualize_segmentation.py --frame 0`
  2. Verify colors in mapping JSON files
  3. Check `repo_to_yolo_seg.py` class mappings match your Isaac Sim semantics

**Problem:** Train/val directories not created
- **Fix:** Ensure `--train_val_split` parameter is between 0 and 1 (exclusive of 1.0):
  ```bash
  python repo_to_yolo_seg.py ... --train_val_split 0.9   # ✅ Creates train/val
  python repo_to_yolo_seg.py ... --train_val_split 1.0   # ✗ Creates flat directory
  ```

### Training Issues

**Problem:** Low mAP on validation
- **Possible causes:**
  - Insufficient training data
  - Domain gap (synthetic vs real)
  - Model underfitting or overfitting
- **Solutions:**
  - Increase `TOTAL_FRAMES` in Isaac Sim generation
  - Add more position/lighting variations
  - Try larger model (`yolov8m-seg.pt` instead of `yolov8n-seg.pt`)
  - Collect real-world validation data for testing

## 📋 Complete Pipeline Summary

### Quick Start (for existing dataset)

```bash
# 1. Verify segmentations are correct
python visualize_segmentation.py --data_dir isaac_raw_output --frame 0 --save
python visualize_segmentation.py --data_dir isaac_raw_output --frame 2700 --save

# 2. Convert to YOLO format (takes ~18 min for 5,100 frames)
python repo_to_yolo_seg.py --in_dir isaac_raw_output --out_dir yolo_dataset --train_val_split 0.9

# 3. Verify polygon annotations
python visualize_yolo_polygons.py --dataset_dir yolo_dataset --split train --num_samples 5
python visualize_yolo_polygons.py --dataset_dir yolo_dataset --split val --num_samples 3

# 4. Train YOLO model
pip install ultralytics
yolo segment train data=yolo_dataset/data.yaml model=yolov8n-seg.pt epochs=100 imgsz=640
```

### Full Pipeline (from scratch)

1. **Setup in Isaac Sim (requires Isaac Sim 5.1)**
   - Ensure Lane and Sphere prims exist in scene
   - Configure Camera prim for desired viewpoint

2. **Generate data** (~30-60 min)
   ```bash
   # In Isaac Sim Script Editor:
   # Open run_ball_script_data_gen.py and run it
   # Generates 5,500 frames with train/val variations
   ```
   Output: `isaac_raw_output/` directory with:
   - 5,500 RGB images
   - 5,500 instance segmentation masks
   - 5,500 semantic segmentation masks
   - JSON mapping files for each

3. **Verify segmentations** (5-10 min)
   ```bash
   python visualize_segmentation.py --data_dir isaac_raw_output --frame 0 --save
   ```
   - Check that lane and ball are properly segmented
   - Check different frames to ensure consistency

4. **Convert to YOLO format** (~18 min)
   ```bash
   python repo_to_yolo_seg.py --in_dir isaac_raw_output --out_dir yolo_dataset --train_val_split 0.9 --workers 15
   ```
   Output: `yolo_dataset/` with proper train/val structure

5. **Verify polygon annotations** (2-5 min)
   ```bash
   python visualize_yolo_polygons.py --dataset_dir yolo_dataset --split train --num_samples 5
   ```
   - Check that polygons tightly fit objects
   - Verify no overlapping or merged segments

6. **Train YOLO model** (30-120 min depending on model size)
   ```bash
   pip install ultralytics
   yolo segment train data=yolo_dataset/data.yaml model=yolov8n-seg.pt epochs=100 imgsz=640
   ```
   - Nano model (yolov8n-seg): Fast training, lower accuracy
   - Medium model (yolov8m-seg): Balanced
   - Large model (yolov8l-seg): Slower training, best accuracy
